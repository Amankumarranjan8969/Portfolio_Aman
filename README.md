## 1. Executive Summary

This repository contains the complete source code, typed data architecture, automated testing suites, and GitHub Actions CI/CD workflows for the official engineering portfolio of **Aman Kumar Ranjan**.

Built as a high-performance, dark technical engineering dashboard, the platform is designed specifically for technical recruiters, engineering directors, research supervisors, and AI/ML evaluation panels.

### Key Architectural Standards:
- **Zero Fabricated Claims**: All counts, project summaries, and model metrics are derived dynamically from verified primary records. Unconfirmed historical items are explicitly categorized as *Needs Verification* or *Experimental*.
- **Empirical Research Benchmarking**: Houses authentic empirical evaluation tables from the candidate's B.Tech dissertation at NIH Roorkee (JAL-SETU: Cubist $R^2 = 0.9467$, CatBoost $R^2 = 0.9041$) and CSIR-CBRI atmospheric modeling research (SuperBlend $R^2 = 0.9180$).
- **Strict Separation of Concerns**: Structured TypeScript schemas decouple static data registers (`src/data/`) from reactive UI presentation components.
- **Deep Accessibility & Performance**: WCAG AA color contrast, responsive sidebar/drawer navigation, keyboard navigation, and lightweight local SVG charts via Recharts.

## 4. Getting Started Locally

### Prerequisites
- Node.js `v20+` or `v24+`
- npm `v10+` or `v11+`

### Installation & Run

```bash
# 1. Clone repository
git clone https://github.com/Amankumarranjan8969/Amankumarranjan8969.github.io.git
cd Amankumarranjan8969.github.io

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev
```

### Running Automated Tests

```bash
# Execute full Vitest suite (15 unit and integration tests)
npm test
```

### Production Build & One-Command Deploy

```bash
# Compile TypeScript and bundle production assets to dist/
npm run build

# Preview production build locally (Port 4173)
npm run preview

# Deploy directly to GitHub Pages (gh-pages branch)
npm run deploy
```
